# 배포 형식별 용도와 조판

이 책은 같은 원고를 네 가지 형식으로 낸다.
형식마다 독자가 읽는 기기와 환경이 달라서 글자 크기와 쪽 구성을 따로 정한다.
수치는 2026-10-09 빌드 기준이다.

## 형식별 추천 용도

| 형식 | 받는 곳 | 추천 용도 | 이런 독자에게 |
|---|---|---|---|
| 웹 사이트 | benelog.github.io/flashcard | 기본 읽기. 항상 최신 원고다. 검색, 북마크·형광펜, 코드 복사가 된다. | 컴퓨터 앞에서 따라 하며 읽는 독자 |
| EPUB | `flashcard-book.epub`(사이트 상단 메뉴·홈 버튼) | 휴대폰·태블릿·전자책 단말기. 글자 크기와 밤 모드를 리더에서 고르고, 받아 두면 인터넷 없이 읽는다. | 이동 중에 읽는 독자, 화면이 작은 기기 |
| A4 PDF | `flashcard-book.pdf`(사이트 상단 메뉴·홈 버튼) | 집이나 회사 프린터로 직접 인쇄해 읽기. 컴퓨터 화면에서 쪽 단위로 넘겨 보기에도 쓴다. | 종이에 메모하며 공부하고 싶지만 종이책을 사지 않는 독자 |
| POD 종이책(B5) | 교보문고 바로출판(등록 예정) | 제본된 종이책. 원고 PDF는 `npm run pod`로 만들고 독자에게 직접 배포하지 않는다. | 책장에 두고 오래 볼 책을 사려는 독자 |

휴대폰에서는 PDF보다 EPUB이 낫다. PDF는 쪽 크기가 고정이라 휴대폰 화면에서는 글자가 너무 작아 확대와 스크롤을 반복해야 한다.

## A4 PDF: 집에서 직접 인쇄하는 판

### 지금 조판

웹 화면용 CSS를 그대로 인쇄한다(`npm run pdf`, `book-template/lib/pdf.mjs`).
아래는 인쇄 미디어로 계산된 값을 잰 것이다.

| 항목 | 값 |
|---|---|
| 쪽 크기·여백 | A4 210×297mm, 위·아래 18mm, 좌우 15mm(홀짝 구분 없음) |
| 본문 | Noto Serif KR 12.75pt(17px), 행간 2.05 |
| 장 제목·절 제목 | 22.8pt·18pt, 고딕 |
| 코드 블록·인라인 코드 | 10.5pt·10.8pt, 시스템 고정폭 글꼴(CI에서는 Liberation Mono), 색 강조 |
| 용어 상자·캡션 | 10.8pt·10.2pt |
| 분량 | 706쪽(표지 1 + 차례 2 + 본문 703), 파일 88MB |

### 집 인쇄를 감안한 판단

지금 수치는 화면에서 읽기 좋게 잡은 값이라 종이로는 크고 성기다.
일반 책 본문이 10~11pt, 행간 1.6~1.8이니 12.75pt·2.05는 한 쪽에 담기는 글이 그보다 훨씬 적다.
집에서 인쇄하는 독자에게는 종이와 잉크가 곧 비용이다.
양면으로 인쇄해도 353장이고, 단면이면 706장이 든다.

A4 판을 집 인쇄에 맞추려면 아래 값을 권한다.
A4는 B5보다 넓어서 본문을 POD 판(10pt)보다 한 단계 키워도 쪽수가 늘지 않는다.

| 항목 | 권장 | 이유 |
|---|---|---|
| 본문 | 명조 11pt, 행간 1.7 | 일반 책 본문 크기다. 펜으로 메모할 행간이 남는다. |
| 장 제목·절 제목·소절 | 20pt·14pt·12pt, 고딕 | |
| 코드 | D2Coding 9pt, 행간 1.45 | 한 줄에 100자 안팎이 들어가 줄바꿈이 거의 없다. |
| 용어 상자·표·캡션 | 9.5pt·9pt·9pt | |
| 여백 | 위 20mm, 아래 22mm, 좌우 20mm | 가정용 프린터는 가장자리 3~5mm를 찍지 못한다. 펀치 구멍이나 바인더 클립 자리도 남는다. |
| 쪽 번호 | 아래 가운데 | 집에서 묶는 책은 홀짝 구분이 없으니 거울 여백도 두지 않는다. |
| 코드 강조 | 흑백 강조(키워드 굵게, 주석 회색 기울임) | 집 프린터는 흑백이 많다. 컬러로 인쇄해도 잉크가 덜 든다. |
| 장 시작 | 새 쪽에서 시작, 오른쪽 면 강제 없음 | 빈 쪽을 줄인다. |

이렇게 바꾸면 쪽수는 약 460쪽(양면 230장)으로 줄 것으로 본다.
POD 판 본문 519쪽에서 판면 넓이와 글자 크기의 비율로 어림한 추정치라, 적용하면 실제로 다시 센다.
글꼴을 POD 판처럼 정적 TrueType(나눔명조·나눔고딕·D2Coding)으로 바꾸면 Type 3가 사라져 파일도 지금의 88MB보다 크게 줄어든다(POD 판은 24MB).

## EPUB

`npm run epub`(`book-template/lib/epub.mjs`)이 만든다.
글자 크기·글꼴·여백은 리더가 정하므로 원고는 상대 크기만 둔다(본문 행간 1.75, 코드 0.8em).
코드 상자는 밤 모드에서도 글자가 보이도록 밝은 바탕에 진한 글자로 고정한다.
글꼴은 넣지 않는다. 파일은 6.7MB이고 대부분 그림이다.

## POD 종이책(B5)

`npm run pod`(`book-template/lib/pod.mjs`)이 `book/.pod/`에 만든다.
조판 수치와 판형을 고른 근거는 [pod-prize.md](pod-prize.md)에 있다.
요약하면 188×254mm, 본문 나눔명조 10pt·행간 1.7, 코드 D2Coding 8pt, 안쪽 22mm·바깥쪽 16mm 거울 여백, 526쪽이다.
