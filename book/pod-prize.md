# 교보문고 바로출판 POD 가격 분석

종이책을 교보문고 바로출판 POD로 낼 때 책값을 가장 낮추는 판형·용지·제본을 정리한다.
가격은 2026-10-09에 파트너 시스템(partner.kyobobook.co.kr) POD등록 화면의 "가격책정 미리보기"에 직접 넣어 확인했다.
미리보기 값은 **예상 최소 정가**다. 실제 정가는 이 값과 같거나 더 높게 100원 단위로 정한다.
웹·EPUB·A4 PDF를 포함한 형식별 용도와 조판은 [formats.md](formats.md)에 있다.

## 결론

| 항목 | 선택 | 이유 |
|---|---|---|
| 판형 | B5(46배판) 188×254mm | 쪽수가 같으면 판형과 관계없이 값이 같다. 큰 판형일수록 쪽수가 줄어 싸다. |
| 인쇄 | 흑백 | 표지만 컬러다. |
| 제본 | 무선(날개 없음) | 날개를 달면 852쪽 기준 4,300원 비싸다. |
| 내지 | 미색모조 80g | 내지 재질은 값에 영향이 없다. 가장 얇은 축이고 긴 글을 읽기에 편하다. |
| 표지 | 스노우 250g 무광 | 아트지 150g과 값이 같다. 두꺼운 책에는 두꺼운 표지가 덜 상한다. |

인쇄용 조판(`npm run pod`)을 적용한 B5 원고는 **526쪽**(본문 519쪽)이다. 아래 쪽당 단가로 계산한 예상 최소 정가는 **약 23,800원**이고, 책등 두께는 약 24.5mm다.
이 두 값은 미리보기에 직접 넣은 값이 아니라 아래 표에서 계산한 추정치다. 원고를 등록할 때 미리보기로 다시 확인한다.

## 가격 구조

### 정가는 쪽수에 정비례한다

B5, 흑백, 무선, 스노우 250g 무광, 미색모조 80g 기준이다.

| 쪽수 | 최소 정가 | 책등 두께 |
|---|---|---|
| 600 | 26,600원 | 27.8mm |
| 800 | 34,100원 | 36.8mm |
| 852 | 36,000원 | 39.1mm |
| 1,000 | 41,600원 | 45.8mm |

쪽당 약 37.5원씩 늘고, 기본료는 약 4,100원이다. 100쪽을 줄이면 약 3,750원이 내려간다.

### 판형은 값에 영향이 없다(A4 제외)

800쪽으로 맞추면 B5, 크라운판, 신국판(NEW A5), 국판(A5), 변형신국판이 모두 34,100원이다.
A4(국배판)만 쪽당 단가가 높아 703쪽에 42,700원이었다.

그래서 판형이 클수록 쪽수가 줄어 싸다. 화면용 조판을 판형별로 인쇄해 센 쪽수로 비교하면 이렇다.

| 판형 | 쪽수 | 최소 정가 | 비고 |
|---|---|---|---|
| B5(46배판) 188×254 | 852 | 36,000원 | |
| 크라운판 176×248 | 927 | 38,800원 | |
| 신국판 152×225 | 1,158 | 47,500원 | 무선제본 한도(1,000쪽)를 넘어 한 권으로 낼 수 없다 |
| A4(국배판) 210×297 | 703 | 42,700원 | 날개·양장 불가 |

### 용지·표지·제본

B5 852쪽 기준이다.

- 내지: 미색모조 80g, 백색모조 80g·100g, 미색모조 100g, 이라이트 80g 모두 36,000원이다. 두께만 다르다(미색·백색모조 80g 39.1mm, 100g 49.3mm, 이라이트 80g 54mm).
- 표지: 아트지 150g과 스노우 250g 모두 36,000원이다. 아르떼 210g, 아트지 250g, 유광 코팅은 확인하지 않았다.
- 제본: 무선 36,000원, 날개 40,300원이다. 양장은 안내문 기준 무선의 3배 이상이고 900쪽까지만 받는다.
- 무선제본은 30~1,000쪽만 받는다.

### 선택할 수 있는 판형 10종

A4(국배판) 210×297, B5(46배판) 188×254, 크라운판 176×248, 신국판 152×225, 정사각판 210×210, 변형신국판 152×210, 국판 148×210, 가로판 254×188, 46판 128×188, 국반판 105×148.
교보의 B5는 업계에서 흔히 쓰는 46배판(188×257)보다 3mm 짧은 188×254다.

### 2025-07-01 정가 인상

흑백 도서는 평균 25%, 컬러 도서는 평균 15% 올랐다. 인상 전에 등록한 책에는 적용되지 않는다.
블로그 등에 남은 예전 판매 사례(쪽당 33원 안팎)는 인상 전 값이다.

## POD 원고 PDF

`cd book && npm run build && npm run pod`를 실행하면 `book/.pod/flashcard-book-pod-b5.pdf`가 생긴다(저장소에는 넣지 않는다). 설정은 `book.config.mjs`의 `pod`, 구현은 `book-template/lib/pod.mjs`다. 그레이스케일 변환에 Ghostscript(`gs`)가 필요하다.

- 쪽 크기: 194×260mm. 책 크기 188×254mm에 재단 여유(사방여백)를 상하좌우 3mm씩 더했다. 글과 그림은 모두 책 크기 안에 있고, 각 쪽에 TrimBox(재단선)와 BleedBox를 적어 두었다.
- 여백(재단선 기준): 위 20mm, 아래 22mm, 안쪽 22mm, 바깥쪽 16mm. 홀짝 쪽에 맞춰 좌우를 거울처럼 바꾼다.
- 구성: 표제지(PDF 1쪽) → 판권(2쪽) → 차례(3쪽부터) → 본문. PDF 1쪽이 책의 오른쪽 면이므로 본문 1쪽도 오른쪽 면(PDF 홀수 쪽)에서 시작한다. 장은 새 쪽에서 시작하되 쪽수를 아끼려고 오른쪽 면을 강제하지 않는다. 전체 쪽수는 짝수로 맞춘다.
- 조판: 본문 나눔명조 10pt·행간 1.7, 제목 나눔고딕, 코드 D2Coding 8pt. 코드는 흑백으로 구분한다(키워드 굵게, 주석 회색 기울임).
- 색: 병합한 뒤 PDF 전체를 그레이스케일로 바꾼다. 그림 37개가 모두 회색조이고 컬러 잉크(C·M·Y) 사용량은 0이다.
- 쪽 번호: 본문에만, 바깥쪽 아래 모서리
- 판권: 교보 개인 작가 양식(발행처 퍼플)을 따른다. 항목은 `book.config.mjs`의 `pod.colophon`에 있다.
- 글꼴: 모두 임베딩된 TrueType이다(Type 3 없음). 나눔명조·나눔고딕은 google/fonts에서, D2Coding은 naver/d2codingfont VER1.4.0에서 처음 실행할 때 받아 `book/.fonts-cache/`에 둔다. A4 PDF도 같은 글꼴을 쓴다.
- 파일: 526쪽, 약 15MB

## 교보 원고 규정 확인 결과

2026-10-09에 파트너 시스템 POD등록 화면의 "등록 전 필수 체크사항"(바로출판 필수체크 안내, 2026.10 갱신)에서 확인했다.

| 규정 | 내용 | 반영 |
|---|---|---|
| 재단 여유(사방여백) | 책 크기에 상하좌우 각 3mm를 더한 크기로 만든다. 사진·글씨는 책 크기 안쪽에 둔다. 예: 신국판 152×225mm → 158×231mm | 194×260mm로 만든다 |
| 쪽 단위 | 한 페이지씩 만든다(두 쪽을 붙인 모아찍기 금지) | 그렇게 만든다 |
| 쪽 방향 | PDF 1쪽이 책의 오른쪽 면이다. PDF 기준 홀수 쪽은 모두 오른쪽 면이다. | 표제지가 1쪽, 본문 1쪽도 홀수 쪽 |
| 흑백 원고 | 흑백 인쇄를 고르면 원고 PDF도 그레이스케일이어야 한다. 색이 남으면 일부가 흐릿하게 찍힐 수 있다. | Ghostscript로 변환한다 |
| 판권 페이지 | 원고 앞이나 뒤에 반드시 넣는다(반려가 잦은 항목). 개인 작가는 양식의 빨간 부분(제목, 발행일, 지은이, ⓒ 저자명 발행연도)만 고친다. | 양식대로 넣었다 |
| 쪽수 | 30~1,000쪽. 50쪽 미만이면 납본 제외 | 526쪽 |
| 글꼴 | 오류 나는 글꼴이 없는지 확인한다(문제가 잦으면 글꼴 아웃라인) | 모두 TrueType 임베딩 |
| 면지 | 앞뒤 1장씩 무료로 넣어 준다. 원고에 따로 넣지 않는다. | 넣지 않았다 |

표지 규정(펼침면 1장, 날개는 각 100mm, 앞과 책등에 퍼플 로고, 뒤표지 오른쪽 아래 55×35mm는 물류 바코드 자리로 비움)은 표지를 만들 때 따른다.
판형·용지·쪽수에 맞는 책등 두께와 표지 파일 크기는 안내 페이지의 "표지·내지 제작 가이드"가 계산해 준다.

## 등록 전에 확인할 것

- 판권의 발행일(`pod.colophon`, 지금 2026년 11월 1일)을 실제 등록 일정에 맞춘다. 교보는 승인 기간을 감안해 여유 있게 잡으라고 한다.
- 판권의 고정 문구("본 책 내용의 전부 또는 일부를 재사용하려면 반드시 저작권자의 동의를 받으셔야 합니다")는 CC BY-NC-SA 라이선스와 결이 다르다. 라이선스 안내 문단을 그 아래 덧붙여 두었는데, 이대로 둘지 교보(pod@kyobobook.com)에 문의해 정한다.
- 원고 파일 크기 제한은 안내에서 찾지 못했다. 지금 PDF는 약 15MB다.
- 표지는 따로 만든다. 책등 너비는 최종 쪽수로 "표지·내지 제작 가이드"나 가격 미리보기에서 확인한다.
- 등록 직전에 미리보기로 최종 쪽수의 정가를 다시 확인한다.
